# DOOM-LIKE

Raycasting FPS в стиле классического **Doom (1993)**.  
Работает на ПК, телефоне и планшете. Устанавливается как **PWA** и работает **офлайн**.

## Возможности

- 5 уровней (E1M1–E1M5)
- 2 типа врагов (зомби / имп)
- Пистолет + дробовик (спред)
- Аптечки и патроны
- Двери (E / кнопка 🚪)
- Миникарта
- Сохранения и рекорды (IndexedDB)
- Процедурный звук
- Полный тач-контроль

## Управление

| Действие        | ПК              | Мобилка              |
|-----------------|-----------------|----------------------|
| Движение        | WASD            | Левый джойстик       |
| Взгляд          | Мышь            | Свайп правой зоной   |
| Стрельба        | ЛКМ / Space     | 🔥                   |
| Смена оружия    | Q               | 🔫                   |
| Открыть дверь   | E               | 🚪                   |
| Пауза           | Esc / P         | —                    |

## Запуск

```bash
# Локальный сервер (нужен для ES modules и PWA)
python -m http.server 8080
# или
npx serve .
```

Открой http://localhost:8080

Для PWA: в Chrome «Установить приложение».

## Добавление нового уровня

1. Создай файл `maps/e1m6.json` (см. формат в существующих)
2. Добавь `"e1m6"` в массив `LEVEL_IDS` в `js/levels.js`
3. В предыдущем уровне укажи `"next": "e1m6"`

Коды тайлов:
- `0` пусто · `1` стена · `2` дверь  
- `3` зомби · `8` имп · `4` старт · `5` выход  
- `6` аптечка · `7` патроны
